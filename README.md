# Idle+

A [Dalamud](https://github.com/goatcorp/Dalamud) plugin for Final Fantasy XIV that shows your current
**Idle**, **Groundsit** and **Doze** `/cpose` numbers, and lets you change them from a small window.

## Commands

| Command | Action |
| --- | --- |
| `/idle`, `/idle+`, `/idleplus` | Toggle the main window |
| `/idleplussettings` | Open the settings window |

## Installation

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste:

   ```
   https://raw.githubusercontent.com/star-in-a-galaxy/IdlePlus/main/repo.json
   ```

3. Click **+**, then **Save and Close**.
4. Type `/xlplugins`, open **All Plugins**, search for **Idle+**, and install it.

A warning that this is a third-party repository is normal.
